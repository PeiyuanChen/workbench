个人工作台 · 本地优先（Local-First）开放数据架构

数据层 = Markdown + iCalendar/CalDAV 开放格式，始终在你手里 · 软件只是一层可替换的皮 · 一套后端服务 Web / iOS / Android

数据主权（地基）

  • • 全部数据 = Markdown + .ics 纯文本
  • • 存在你 D 盘 / 自托管服务器，离线可用
  • • 软件关停、换框架：数据原样可读可迁
  • • 四象限/时间线是"视图"，非私有数据结构

一套后端，多端复用

  • • 后端只做"开放文件 → 视图 JSON"
  • • Web 先行（响应式 PWA，手机浏览器也能用）
  • • iOS/Android 后期接同一 API，不重写数据
  • • CalDAV 标准让第三方 App 也能直连

AI 是帮手不是依赖

  • • 迁入：旧 App 导出 → AI 转成 .md/.ics
  • • 迁出：开放格式 → AI 转目标产品模板
  • • 源是标准格式，转换可逆、可 diff、可校验
  • • 即使没有 AI，数据本身也能被通用工具打开
