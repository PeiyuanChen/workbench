# 笔记文件夹以真实文件系统子目录为唯一真相源

笔记的文件夹分类不引入任何 sidecar 元数据或私有索引文件：文件夹就是 `notes/` 下的真实子目录，笔记的 frontmatter 不写 folder/path 字段，相对路径即唯一真相源。

## 考虑过的备选

- **sidecar 索引文件 / frontmatter 记录 folder**：被否。产生应用私有数据，违背数据主权第一性原则（数据必须能被记事本、Obsidian 等通用工具直接理解），并带来索引与文件系统的一致性维护成本。

## 后果

- 在资源管理器或 Obsidian 中直接拖动文件即等于移动笔记，应用重启后自然识别。
- 移动/重命名文件夹即文件系统操作；笔记移动时只换目录，文件名日期前缀与 id 不变。
- 列表 API 返回扁平结构（`folders` + 带 `folder` 字段的 items），前端组树，后端不持有树状态——与「视图 ≠ 数据」原则一致。
- 图片资产平铺于 `notes/assets/`，文件名以文件夹路径为前缀（如 `kubernetes__20261108-153012-a1b2c3d4.png`）；笔记移动改变目录深度时，正文内资产相对链接必须同步改写。
- 非空文件夹拒绝删除（422），空文件夹才可删；保留名 `.backup`、`assets` 禁止作为文件夹名。
- 备忘模块保持平铺，不引入文件夹。
